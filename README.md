# Duelink

**Duelink** — браузерная multiplayer-платформа мини-игр на двоих. Один игрок создаёт приватную комнату, отправляет ссылку другу, и оба сразу играют в обычном браузере с телефона, планшета или компьютера.

Никакой обязательной регистрации. Никакого лаунчера. Никакого одинакового Wi-Fi.

## Игры

- Крестики-нолики
- Четыре в ряд
- Камень / Ножницы / Бумага
- Морской бой
- Точки и квадраты
- Быки и коровы

Для каждой игры в интерфейсе есть краткое описание, время партии, сложность и отдельное окно с правилами и примером. При первом запуске конкретной игры правила показываются автоматически.

## Возможности

- приватные комнаты максимум на 2 игроков;
- вход по ссылке вида `/room/ABC123` или по короткому коду;
- real-time синхронизация через Socket.IO;
- серверная проверка ходов и скрытых данных;
- переподключение после обновления страницы;
- адаптивный интерфейс для desktop и mobile;
- заметные экраны победы, поражения и ничьей;
- звуки ходов, подключения и результатов без внешних аудиофайлов;
- включение и выключение звука с сохранением настройки;
- нативная кнопка «Поделиться» на поддерживаемых телефонах;
- лёгкая вибрация при действиях на совместимых мобильных устройствах;
- встроенные правила для всех игр;
- анимации, confetti при победе и отдельные визуальные состояния игроков;
- комнаты автоматически очищаются после ухода игроков.

## Почему это не просто «крестики-нолики»

Проект демонстрирует полноценную клиент-серверную архитектуру: создание комнат, идентификацию игроков, real-time события, reconnect, серверную игровую логику, скрытое состояние, адаптивный UI и развёртывание публичного Node.js-сервиса.

Например, в «Быках и коровах» секретное число соперника не отправляется второму клиенту до завершения матча. Сервер сам считает быков и коров, поэтому скрытая информация не лежит в браузере игрока.

## Технологии

- Node.js
- Express
- Socket.IO
- Vanilla JavaScript
- HTML / CSS
- Web Audio API
- Web Share API
- Railway для публичного развёртывания

## Локальный запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открыть:

```text
http://localhost:3000
```

## Публичная версия

Проект разворачивается как обычный Node.js Web Service. После деплоя игрокам не нужны Node.js, GitHub или какие-либо приложения. Они просто открывают публичную ссылку в браузере, создают комнату и отправляют приглашение второму игроку.

## Структура

- `server.js` — комнаты и серверная игровая логика
- `public/index.html` — основной интерфейс
- `public/app.js` — базовая клиентская логика
- `public/extra.js` — дополнительные игры, звуки и экраны результата
- `public/portfolio.js` — onboarding, правила, sharing и презентационный UX
- `public/styles.css` — базовый дизайн
- `public/extra.css` — игровые компоненты и результат матча
- `public/portfolio.css` — финальный слой визуального polish
