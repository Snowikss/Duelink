# Duelink

**Duelink** — браузерная multiplayer-платформа мини-игр на двоих. Один игрок создаёт приватную комнату, отправляет ссылку другу, и оба играют в обычном браузере с телефона, планшета или компьютера.

Главная идея проекта: **одна ссылка на комнату, несколько игр внутри одного лобби**. Игрокам больше не нужно создавать новую комнату и снова пересылать приглашение после каждой партии.

## Игры

- Крестики-нолики
- Четыре в ряд
- Камень / Ножницы / Бумага
- Морской бой
- Точки и квадраты
- Быки и коровы
- Пять в ряд
- Реверси

Для каждой игры в интерфейсе есть понятное описание и правила. Менее знакомые игры объясняются прямо внутри Duelink, чтобы пользователю не приходилось заранее знать механику.

## Next-Gen Lobby

- постоянная приватная комната максимум на 2 игроков;
- ссылка и код комнаты не меняются при смене игры;
- создатель комнаты выбирает игру и запускает матч;
- оба игрока подтверждают готовность;
- после готовности запускается анимированный countdown `3 → 2 → 1 → GO!`;
- после матча создатель может вернуть обоих игроков в то же лобби;
- если связь временно пропала, слот игрока сохраняется для переподключения;
- смена игры сбрасывает готовность, но не разрывает комнату.

## Возможности

- вход по ссылке вида `/room/ABC123` или короткому коду;
- real-time синхронизация через Socket.IO;
- серверная проверка ходов и скрытых данных;
- переподключение после обновления страницы;
- responsive UI для desktop и mobile;
- строгая desktop-компоновка игровой комнаты без наложения sidebar на игровую область;
- анимированные состояния лобби, готовности и старта матча;
- экраны победы, поражения и ничьей;
- confetti при победе;
- звуки действий и результатов через Web Audio API;
- включение и выключение звука с сохранением настройки;
- нативная кнопка «Поделиться» на поддерживаемых телефонах;
- лёгкая вибрация на совместимых мобильных устройствах;
- встроенные правила игр;
- собственный логотип и favicon;
- автоматическая очистка заброшенных комнат.

## Серверная архитектура

Сервер является источником истины: клиент не может самостоятельно назначить себе победу, сменить игру без прав создателя комнаты или подсмотреть скрытые данные.

В «Быках и коровах» секретное число соперника не отправляется другому клиенту до завершения матча. Сервер сам рассчитывает количество быков и коров. В «Реверси» сервер вычисляет допустимые ходы и переворачивает захваченные фишки, а в «Пять в ряд» проверяет победную линию после каждого хода.

Состояние комнаты разделено на две фазы:

```text
Lobby -> Ready -> Match -> Lobby
```

При смене игры меняется игровое состояние, но сама комната и её URL остаются прежними.

## Локальный запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открыть:

```text
http://localhost:3000
```

## Публичная версия

Проект разворачивается как обычный Node.js Web Service. Игроку не нужны Node.js, GitHub, приложение или одинаковый Wi-Fi. Достаточно открыть сайт и получить ссылку на комнату.

## Структура

- `server-v2.js` — текущий сервер комнат, lobby state и логика 8 игр
- `server-nextgen.js` — предыдущая next-gen серверная реализация
- `server.js` — ранняя серверная реализация
- `public/index.html` — основной интерфейс
- `public/app.js` — базовая клиентская логика
- `public/extra.js` — дополнительные игры, звуки и экраны результата
- `public/portfolio.js` — onboarding, правила, sharing и презентационный UX
- `public/nextgen.js` — next-gen lobby, ready flow и countdown
- `public/v2.js` — «Пять в ряд», «Реверси» и расширение лобби
- `public/styles.css` — базовый дизайн
- `public/extra.css` — игровые компоненты и результат матча
- `public/portfolio.css` — презентационный слой интерфейса
- `public/nextgen.css` — lobby UI и расширенные анимации
- `public/v2.css` — desktop layout fix и стили новых игр
- `public/duelink-avatar.svg` — логотип проекта
