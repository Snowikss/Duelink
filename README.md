# Duelink

Браузерная платформа мини-игр на двоих с приватными комнатами по ссылке.

## Уже работает

- Крестики-нолики
- Четыре в ряд
- Камень / Ножницы / Бумага
- Морской бой
- Комнаты максимум на 2 игроков
- Вход по ссылке вида `/room/ABC123`
- Realtime-синхронизация через Socket.IO
- Переподключение после обновления страницы
- Адаптивный интерфейс для ПК и телефона
- Серверная проверка ходов

## Локальный запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открыть: `http://localhost:3000`

## Публикация в интернете

В корне есть `render.yaml`, поэтому репозиторий подготовлен для Render.

После публикации игрокам не нужны Node.js, GitHub или приложения. Они просто открывают публичную ссылку в браузере с телефона или ПК, создают комнату и отправляют ссылку второму игроку.

## Структура

- `server.js` — сервер комнат и игровая логика
- `public/index.html` — интерфейс
- `public/styles.css` — оформление и мобильная адаптация
- `public/app.js` — клиентская логика
- `render.yaml` — настройки размещения на Render
